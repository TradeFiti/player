# Self-hosted font licences

The profile uses only locally served fonts. Each family below is distributed under the SIL Open Font License 1.1; the corresponding upstream `OFL.txt` is included in this directory.

- Archivo — `archivo-var.woff2` — `archivo-OFL.txt`
- Big Shoulders Display — `big-shoulders-display-var.woff2` — `bigshouldersdisplay-OFL.txt`
- Bricolage Grotesque — `bricolage-grotesque-var.woff2` — `bricolagegrotesque-OFL.txt`
- Fraunces — `fraunces-var.woff2`, `fraunces-var-italic.woff2` — `fraunces-OFL.txt`
- Geist — `geist-var.woff2` — `geist-OFL.txt`
- IBM Plex Mono — `ibm-plex-mono-400.woff2`, `ibm-plex-mono-500.woff2` — `ibmplexmono-OFL.txt`
- Instrument Serif — `instrument-serif.woff2`, `instrument-serif-italic.woff2` — `instrumentserif-OFL.txt`
- Newsreader — `newsreader-var.woff2`, `newsreader-var-italic.woff2` — `newsreader-OFL.txt`

Licence files were retrieved from the official Google Fonts repository paths for these families. Keep the relevant `OFL.txt` with any redistributed font binaries.
